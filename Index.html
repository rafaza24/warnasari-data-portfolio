Ekspor & Impor Data Master

Pusat cadangan data (.json) dan migrasi data otomatis antar aplikasi Desa Warnasari.

📦 Ekspor Master Data (.json)

FORMAT RESMI BACKUP DUSUN 1

Mengemas seluruh data warga 6 tabel (Data Warga, Mutasi Datang/Pergi, Kelahiran, Meninggal, Pengontrak) ke dalam 1 file JSON resmi untuk dipindahkan ke aplikasi 1 Desa nanti.

📥 Impor Master Data (.json)

PENGGABUNGAN DATA OTOMATIS

Mengunggah dan memasukkan ratusan data warga dari file backup .json ke aplikasi tanpa perlu mengetik ulang data manual. Dilengkapi fitur anti-duplikat NIK.
